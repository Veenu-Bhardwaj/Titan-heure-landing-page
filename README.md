# TITAN HEURE

A single-page Next.js landing site built as a front-end development
internship assignment. The concept: **Titan — a well-known Indian
watch and accessories brand famous for precision engineering —
reimagined as a luxury fragrance house.**

## Concept

Titan's identity is built on precision movements and craftsmanship.
TITAN HEURE (French for "hour") takes that same promise and applies
it to scent: precision-blended accords, individually numbered
bottles, and a "Fragrance Movement" structure — top, heart, and base
notes laid out like the layers of a watch movement.

## Tech Stack

- Next.js (App Router)
- Tailwind CSS
- Deployed on Vercel

## Running Locally

```
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Build

```
npm run build
npm start
```
